# Student Skill Exchange

A diploma project at Astana IT University.

We are building a web platform where university students can learn
from each other by exchanging skills. For example, someone who knows
Python and wants to practise English could find a student who offers
English practice and wants help with Python.

**Diploma topic:** Development of a Peer-to-Peer Skill Exchange
Platform for University Students.

## Why we are building this

We want to explore whether students can find learning partners more
easily when they can see what others know and what they want to learn.

Our starting assumption is that finding a suitable person through
student chats can take time, especially when both people want
something in return. We still need to check this through conversations
with students before treating it as an established problem.

## Who it is for

University students who want to share what they know and learn
something new from their peers.

## What we plan to build

The first version will let students:

- Create an account and fill out a profile.
- List skills they can teach and skills they want to learn.
- Search for other students by skill.
- See suggested partners with matching learning interests.
- Send and respond to exchange requests.
- Agree on the topic, time, and format of an exchange.

We will keep the first version focused on finding a partner and
arranging an exchange. Built-in video calls, payments, a mobile app,
and machine learning are outside its scope.

## Our goal

By the end of the project, we aim to have a working web application
that supports the full journey from registration to an agreed exchange.

We will test the main user flows and evaluate how well the matching
approach helps students find suitable partners. The project will also
include API documentation and instructions for using the platform.
